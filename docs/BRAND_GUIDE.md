# Ilelah Technologies brand guide

## The idea

The mark is a lowercase **i** on a navy tile, with a **gold diamond** where the dot would be. The diamond is a *node*: a connection point in a network. It nods to the founder's Computer and Communications Engineering background, and to the business connecting software, schools, support and training.

The same node appears across the website: as list bullets, in the homepage schematic and as small accents. Used consistently, it becomes recognisable even without the name.

The mark is deliberately different from the **Ilelah Business Suite** "IS" product icon. Products may have their own icons, but company materials use the Ilelah Technologies mark.

The text in every logo file is converted to outlines, so it looks the same everywhere, even without the font installed.

**For printers and embroiderers:** send the SVG files. They scale to any size without losing quality. For embroidery, use the mono files. Gold thread can replace the white diamond on the navy mono mark if the embroiderer can do two colours.

### Usage rules

- Keep clear space around the logo of at least the height of the gold diamond on every side
- Minimum size: horizontal logo **24 px** tall on screen or **8 mm** in print; mark alone **16 px** or **5 mm**
- Do not stretch, rotate, recolour, add shadows or outlines, or place the logo on busy photos
- Do not rebuild the logo in another font. Always use the supplied files.
- On colours other than white or navy, use the mono black or mono white versions

### Regenerating the files

The files are generated by `scripts/brand/build_brand.py` from the brand colours and the Schibsted Grotesk font. To regenerate after a colour change:

```powershell
pip install fonttools brotli uharfbuzz playwright pillow
python -m playwright install chromium
npm run brand
```

## Colour

| Name | Hex | Use | Contrast |
| --- | --- | --- | --- |
| **Navy** | `#0F2A4A` | Primary brand colour: headings, buttons, links, the mark's tile | 14.5:1 on white |
| Navy deep | `#0A1D35` | Footer and dark bands | |
| **Gold** | `#C8A24A` | Accent only: the node, thin rules, highlights. Text in gold only on navy (6.0:1). | 2.4:1 on white, so **never gold text on white** |
| Gold ink | `#7A5C12` | When a gold-family text colour is needed on white | 6.2:1 |
| Ink | `#12161C` | Body text | 18.2:1 |
| Ink soft | `#4A5363` | Secondary text | 7.8:1 |
| Mist | `#F4F6F9` | Quiet section backgrounds | |
| Line | `#DFE3EA` | Borders and dividers | |
| White | `#FFFFFF` | Main background | |

Roughly: **white 70%, navy 20%, gold 5%, everything else 5%.** Gold is precious. If it is everywhere, it stops meaning anything.

Print equivalents are approximate. Ask your printer to match the hex values, or request a proof:

- Navy ≈ CMYK 100 / 72 / 32 / 52
- Gold ≈ CMYK 20 / 33 / 80 / 4

## Typography

**Schibsted Grotesk** for everything: headings at weight 700–760, body text at 400, labels and buttons at about 620–640. It is a free, open-licence typeface (SIL Open Font License), available from Google Fonts for Word, Canva and print work.

- Headings: sentence case ("How we work", not "How We Work"), tight letter spacing
- Body: 17 px on screen, line length under about 70 characters
- Avoid ALL-CAPS labels and decorative fonts
- Fallback when Schibsted Grotesk is not available: Arial

## Voice

- Plain, specific and honest. Say what something does, not how innovative it is.
- Write for the customer's problem: "Results are late every term" beats "Next-generation assessment".
- Sentence case for headings and buttons. Buttons say exactly what happens: "Send quote request", "Request a demo".
- Never claim clients, numbers, awards or certifications that are not verified.

## Applications

| Item | Guidance |
| --- | --- |
| **Business cards** (85 × 55 mm) | Front: horizontal logo on white, or reverse logo on navy. Back: name, role, phone, email, website. A small gold rule (about 12 × 1 mm) under the name is the only gold needed. |
| **Letterhead** | `docs/brand-templates/letterhead.html`. Open in Chrome or Edge and print to PDF. Once the company is registered, add the registered name and number to the footer if the law requires it. |
| **Email signature** | `docs/brand-templates/email-signature.html` |
| **Staff ID cards** | Navy band across the top with the reverse horizontal logo; photo and name on white; gold node beside the role |
| **Branded clothing** | Mark or stacked logo on the chest, in mono white on navy garments or full colour on white garments. Website address across the back if wanted. |
| **Social media** | Profile picture: `ilelah-mark-1024.png`. Posts: white or navy backgrounds, Schibsted Grotesk, one gold accent. |
| **App icons** | `icon-512.png` / `ilelah-mark-1024.png` for company tools. Products such as Business Suite keep their own icon. |

## Design tokens on the website

All colours, sizes and spacing live in `src/styles/tokens.css`. Change a value there and the whole site follows. Keep `scripts/brand/build_brand.py` in step if you change the navy or gold.
